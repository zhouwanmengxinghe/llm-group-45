# QuixBugs development fixtures

These small Python tasks are development and smoke-test fixtures. They are not the final thirty-task SWE-bench cohort. Inspect each task directory and manifest before running; use the CLI `run` or `batch` commands with a trusted local executor or an existing compatible Docker image. Never combine development-fixture scores with the final thirty-task denominator. Candidate patches are stored in separate output directories and require explicit review/application.
