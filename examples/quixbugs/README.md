# QuixBugs Python 小规模测试集

这里是从 [QuixBugs 官方仓库](https://github.com/jkoppel/QuixBugs) 选取的 15 个 Python 缺陷案例，供 PatchLab 本地开发和功能测试使用。每个文件夹互不依赖，包含原始缺陷程序、上游 pytest 测试、对应的 JSON 测试数据及 MIT 许可证；没有包含官方参考修复。

来源版本：`4257f44b0ff1181dedaedee6a447e133219fcebf`。复制时仅统一了文本换行符，以便 PatchLab 生成补丁。

## 在页面中运行

1. 双击项目根目录的 `start.cmd`，打开 PatchLab。
2. 切换到“修复任务”，右侧选择“简易模式”。
3. 项目路径选择下面任意一个案例目录；在输入框粘贴对应的问题描述并发送。
4. 在过程记录中查看 AI 是否成功复现、修复，以及已有测试是否通过。程序会在本机临时副本执行测试，不要直接把结果当作正式基准成绩。

示例目录如果位于当前课程电脑，对应路径以 `D:\School\HKU-7608LLM\agent\patchlab\examples\quixbugs\` 开头。也可在文件管理器中打开目标文件夹并复制地址栏的完整路径。

简易模式使用目录的当前文件，无需将每个案例单独初始化为 Git 仓库。它会尝试生成自己的复现测试，然后运行检测到的既有测试；如果不能从自然语言可靠复现，需补充输入和预期输出。专业模式需要有 Git 版本和手动指定测试，应为要用的案例另建 Git 仓库并提交原始文件。

这些案例用于开发调试；正式对比时还需要预先冻结任务清单、模型、预算、测试流程，并独立记录原始结果。
